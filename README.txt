VÉRA FASHION STORE
===================

Files:
- index.html
- style.css
- script.js
- images/

Features:
- Responsive fashion store landing page
- Category sections
- Product cards
- Search
- Basic cart counter
- Wishlist button placeholder
- Mobile-friendly layout

How to run:
1. Keep all files in the same folder.
2. Keep the images folder beside index.html.
3. Open index.html in a browser.

Important:
This is a frontend template. Payment, real inventory, authentication, database,
shipping and production checkout must be connected before commercial deployment.

Image assets in this package were generated for this demo template.
